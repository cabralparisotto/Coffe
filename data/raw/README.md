# Tabelas para análise

Os arquivos CSV desta pasta foram copiados sem alterações da pasta original
`../../../coffee_specialty_500plus/`.

- `tabela_1_exportacoes_brasil_cafe_torrado_500plus.csv`: exportações
  brasileiras mensais de café torrado não descafeinado (NCM 09012100), de 2015
  a 2024, detalhadas por país de destino e UF.
- `tabela_2_importacoes_paises_cafe_torrado_500plus.csv`: importações mensais
  de café torrado não descafeinado (HS 090121) em 2023, reportadas por 50 países
  com parceiro Mundo.

Os códigos NCM 09012100 e HS 090121 são proxies para café especial, mas
identificam café torrado não descafeinado e não certificação ou categoria
comercial de café especial. Consulte o README da pasta original para detalhes e
limitações das fontes.
